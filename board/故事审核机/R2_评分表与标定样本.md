# R2：评分表 v0 与标定样本（T20261015-02）

用途：评委（全新 Claude、豆包、Google）对**同一份文字稿**独立打分。样本已匿名并打乱顺序，评委看不到来源、数据和作者。

## 一、评分表 v0

先写一句话：**"我最想否决它的理由是……"**（没有就写"没有"）。再打分。凭个人判断而没有依据的写"（无依据）"。

### 硬门槛（每条填：过 / 不过 / 看不出）
- G1 主线任务：能用一句话说出角色要完成的一件事。
- G2 逐步升级：阻碍至少两层，后一层比前一层更难或更荒谬，不是同一种阻碍重复。
- G3 主角有变化：结尾比开头多了点什么（知识、关系、状态、认知），不只是"事情做完了"。
- G4 静音可读：不看字幕、不听旁白，只看每镜动作，也能看懂在讲什么。
- G5 贯穿物：有一个每镜都能看见的物件或线索把各镜串起来。（Claude 的裁决：G5 只在有分镜的阶段判，3 句话梗概阶段不判，见 R1 评论后的 R2 评论）

### 打分（1 到 5 分，整数，不留空）
- 3 秒懂：前 3 秒的画面和动作，观众能不能知道"谁要做什么"。
- 笑点或看点：有多少个，位置是否分散，是否重复同一种。
- 主线完整度：任务、阻碍、转折、收束是否齐全，是否一环扣一环，换顺序会不会没区别。

### 判定
- 任何一条硬门槛"不过" → 不放行，退回改。
- 三项打分里有一项 ≤2 → 不放行。
- 放行还要主人点头；主人不笑就不做。

## 二、标定样本（文字梗概，来源均已隐去）

**S1**

**S2**
一个吉祥物角色摆摊，吆喝"回收旧彩电、旧冰箱、旧洗衣机、旧手机，换盆"。上门收货时把人家屋里翻了个遍，被问"你这是要干嘛，抄家吗"。到此结束。

**S3**
一只高冷的猫在国庆七天里天天有零食、有人陪玩。上班第一天闹钟响，猫躺在零食包装袋中间发呆。主人出门，猫说"终于清静了"。猫碗里变回普通猫粮，它不敢相信。客厅空荡荡，它趴着，尾巴拍两下，自称得了节后综合症。傍晚门响，它前爪搭上门框又缩回，假装只是路过舔毛。第二天早上主人去拿鞋，猫四脚朝天抱住鞋不放，字幕写"今天周六调休上班"。

**S4**
三只小麒麟游三明。最小的那只一路只想吃沙县小吃，每到一处景点都被眼前的东西拦住，比如在万寿岩，它咬了一口平整的石板。到红军街那站，它安静地站着。最后三只吃到小吃，最小的打了个嗝，三只坐船游湖，镜头拉远成全景。

**S5**
小猫不肯睡觉。屋里来了四个"大王"轮番吓它：迷糊大王、病菌大王、暴躁大王、矮个大王。最后小猫决定马上睡觉。

**S6**
局长夫人闹着要告局长藏私房钱。旁边的下属翻出民法典第一千零六十二条，讲夫妻共同财产怎么算，把夫人劝走了。

**S7**
小流浪猫茉莉的大伯来家里借住。茉莉很紧张，不会招待，只能拿自己最爱喝的饮料端给大伯。大伯很感动，回赠了一个罐头。
