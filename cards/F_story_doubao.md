# F 部分：豆包的 3 句话故事（R3 任务 2，随机种子 20261015）

## 我的选择
- 角色关系：**a. 宝宝打工，灵灵当挑剔顾客兼拦手，奇奇带路**。
  理由：主角是宝宝，他最大的欲望是"吃"，让他去给别人送吃的，反差和喜剧动力最强；变化弧（偷吃的小馋猫→认真送单的小师傅）也落在他身上。
- 地点（3 个）：**①麒麟阁（集合点、开张）②万寿岩（平整石铺地面）③泰宁金湖（丹霞水面，奇奇在船上等单）**。不选红军街（庄重，不适合笑点）。
- 训练模式说明：顾客是自家人奇奇（先到船上等单），不出现真人；"沙县小吃"身份只用蒸笼、蒸饺这类视觉物承载，画面不出现可读文字。

## 3 句话故事
1. 在麒麟阁开张的"沙县小吃上门服务"，宝宝背上一摞蒸笼当小工，要把一笼蒸饺送到金湖的船上去，灵灵扮挑剔顾客一路挑刺、奇奇先到船上等单。
2. 过万寿岩，宝宝看见平整的石铺地面，把蒸笼一个个摆开"趁热保温"，被灵灵误以为在遗址上乱摆摊、当场拦住（第一层：误会）；赶到金湖，一阵风把蒸笼吹上水面、倒扣漂走，眼看蒸饺全毁、订单要砸（第二层：更难的意外）。
3. 倒扣的蒸笼却稳稳浮在水面上，宝宝干脆把蒸饺码在蒸笼面推到船边，本来捣乱的"水和蒸笼"变成了最地道的水上送餐，奇奇竖起大拇指，只想着偷吃的小馋猫第一次把蒸饺完整送到、成了小师傅，灵灵也把第一只蒸饺奖给了他。

## 逐要素自检
| 要素 | 落点 |
|---|---|
| 主线任务 | 宝宝把一笼蒸饺从麒麟阁送到金湖船上（上门服务） |
| 升级第一层 | 万寿岩摆蒸笼"保温"，被灵灵当乱摆摊拦住（误会） |
| 升级第二层 | 金湖蒸笼被风吹落、倒扣漂走（任务直接要失败） |
| 转折（障碍变助力） | 落水倒扣的蒸笼反而浮成水上托盘，完成"水上送餐" |
| 主角/关系变化 | 宝宝：偷吃的小馋猫→完整送单的小师傅；灵灵：一路挑刺→把第一只蒸饺奖给他 |
| 蒸笼每阶段出现 | 麒麟阁背上→万寿岩摆石板→金湖落水浮起当托盘，三阶段都在 |
| 本地特征 | 麒麟阁集合点、万寿岩平整石铺地面（真实遗迹特征）、金湖丹霞水面 |
| 笑点/看点 | 把遗址当地桌摆蒸笼、蒸笼倒扣像小船、宝宝护蒸饺 |

## 已规避的风险（详见评论唱反调）
- 万寿岩是遗址，宝宝是"误摆、被拦住"，没有任何破坏动作；石铺地面当"天然桌子"是误会不是损害。
- 金湖蒸笼落水后完整捞回、蒸饺码在蒸笼上，画面干净，不出现垃圾。
- 不出现真人、人群、可读文字、夜景、敬礼。
