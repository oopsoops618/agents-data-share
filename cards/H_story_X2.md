# H 部分：X2 改进版（R4 任务 2，3 句话，4 个节拍）

## 选择（沿用 X）
- 角色关系：a. 宝宝打工，灵灵当挑剔顾客兼拦手，奇奇在金湖船上等单。
- 地点（3 个）：麒麟阁（开张）→ 万寿岩（平整石铺地面）→ 泰宁金湖（丹霞水面）。

## X2 三句话
1. 麒麟阁开张"沙县小吃上门服务"，宝宝背上一摞蒸笼，去给金湖船上的奇奇送一笼蒸饺，灵灵当挑剔顾客一路挑刺、不许他偷开盖。
2. 过万寿岩，木栈道颠簸，蒸笼里的蒸饺眼看要洒，灵灵把他拉到平整的石铺地面旁，让他把手里的蒸笼端平——"放平了就不洒"；宝宝急着赶路又在栈道上小跑，被灵灵当成捣乱挡路、当场拦下（升级一：手忙脚乱加被拦）；到了金湖，船板晃、风又大，一笼蒸笼被吹落、倒扣在水面上漂走（升级二：任务要砸）。
3. 宝宝想起"放平才稳"，急中生智把倒扣的蒸笼当浮盆，用竹篙稳稳勾到船边，开盖时蒸饺还热着——本来要砸的单子变成了最快的水上送餐，总想着偷吃的小馋猫第一次把蒸饺完整送到、成了小师傅，灵灵挑不出刺，把第一只蒸饺奖给了他。

## 节拍（4 个，压到 40 秒可承载）
1. 麒麟阁接任务、背蒸笼出发。
2. 万寿岩：栈道颠簸→平整石铺地面旁学"端平"→急着小跑被拦（伏笔+升级一）。
3. 金湖：蒸笼被风吹落、倒扣漂走（升级二）。
4. 倒扣蒸笼当浮盆、竹篙勾回、开笼还热；小馋猫变小师傅，灵灵奖励（转折+收束）。

## 改了什么 / 没改什么
| 项 | 说明 |
|---|---|
| 改①节拍 | 从 X 的八九个压到 4 个，删掉零散动作，避免赶场。 |
| 改②万寿岩因果 | 不再把蒸笼摆到遗址地面；改为栈道颠簸→在平整石铺地面**旁**学"端平"，石板只做教学现场，"放平才稳"成为金湖转折的伏笔。 |
| 改③水面风险 | 不再把蒸饺放湖面推；蒸饺全程在笼内，蒸笼倒扣当浮盆，用竹篙勾回，开笼还热，食物不碰水。 |
| 改④转折靠行动 | 转折从"巧合式浮托盘"改为宝宝主动想起伏笔、用竹篙勾回，解决"主角无行动"。 |
| 没改 | 关系 a、三地点（麒麟阁/万寿岩/金湖）、蒸笼贯穿每阶段、障碍变助力、宝宝变化弧（小馋猫→小师傅）、灵灵奖励第一只蒸饺。 |
| 仍守住 | 无真人、无人群、无可读文字、无夜景、无敬礼；不选红军街；蒸笼三阶段：背上→端平→倒扣浮回。 |
