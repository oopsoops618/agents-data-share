# I 部分：地点特征 → 动作/障碍池（R5 任务 1）

> 日期：2026-10-15 ｜ 豆包 R5 交付
> 规则：每条只写画面里能拍出来的真实特征（景物、材质、人们在那里做的事、游客体验），不写年代数字和历史评价；每条后跟"这个特征能逼出的动作或障碍"。
> 每条特征后括注实际打开的来源链接（本次均已打开）。
> 总体风险提示：万寿岩、客家祖地、南溪书院属庄重/文物场所，搞笑动作只能是"被拦住/学规矩"，不能是搞破坏、嬉闹、摆拍吃食。

## 1. 麒麟阁（山顶集合点）
- 特征：麒麟阁建在麒麟山的最高处，八角六层，登阁可将远近景色尽收眼底（山顶视野开阔）。
  → 逼出动作：出发前在阁前俯瞰全城、用手指路线（天然的"全局起手"镜头）；背蒸笼爬台阶登高，累得喘气、东西直晃。
- 特征：山北有一片人工湖，湖上有五曲桥，桥身弯来弯去，还有电动龙舟环湖。
  → 逼出动作：过弯桥时蒸笼左右晃、转弯必须端平（"平/稳"的功课可以在非文物的桥面上发生）。
- 特征：上山有吊椅式索道，吊椅悬空、腿悬空。
  → 逼出动作：抱着蒸笼坐吊椅，东西悬空晃荡，宝宝不敢动。
  来源：https://sanming.cncn.com/jingdian/qilinshan/profile （已打开）。注：用户提到的"金色麒麟雕像"本次未在打开页面核实，不写。

## 2. 万寿岩（洞穴遗址，文保单位）
- 特征：船帆洞洞口像张开的船帆，进洞沿木质走道参观，走道狭长。
  → 逼出动作：只能单列走、不能跑，背蒸笼侧身让行，急着赶路被"窄"逼慢。
- 特征：洞内有人工石铺地面遗迹，石块是石灰岩角砾、排放较平、颜色深，旁边有排水沟槽，只能看、不能踩不能碰。
  → 逼出动作：宝宝本能想把冒热气的蒸笼往"平的地方"放，被灵灵一把拦住（"平却不能碰"的反差，不碰遗迹）。
- 特征：灵峰洞在山坡上，要拾级而上，洞口朝西南、洞身高，光线从洞外照进来。
  → 逼出动作：抬着蒸笼爬台阶（明→暗），一颠一颠；洞口逆光剪影。
  来源：https://www.museumschina.cn/museums/details?id=35020521800001 （已打开）

## 3. 泰宁金湖（水上丹霞，全程坐船）
- 特征：大赤壁是一片宽约500米、高约100米的赤红色峭壁，寸草不生，倒影红透湖水，只能在船上远观。
  → 逼出动作：船行到大赤壁前，红色巨壁压顶，风把东西吹向水面，宝宝背对巨壁护住蒸笼。
- 特征：水上一线天是一条宽仅2米、长300多米的水巷，大船进不去，只能换小船擦崖而过，尽头是圆形深潭。
  → 逼出动作：东西要在两船之间递、换船，窄处伸手能摸到两侧崖壁（天然的"第二层、更难"的障碍）。
- 特征：甘露岩寺建在一个上宽下窄的倒三角形岩洞里，靠一根木柱撑起几座重楼，不施片瓦，船靠码头后要登石阶。
  → 逼出动作：独柱前空间窄、抬头看，东西在石阶上传递；一根柱子的"撑/稳"可以做视觉伏笔。
  来源：http://www.fjsmlib.cn/index.php?m=content&c=index&a=show&catid=55&id=274 （已打开）；http://fjsyhzh.com/zh/feiyibaiwen/7069.html （已打开）

## 4. 沙县小吃（夏茂镇俞邦村，"沙县小吃第一村"）
- 特征：村里有"寻根追味"小吃街，沿街灯盏糕、水晶烧麦、手打扁肉、烫嘴豆腐热气腾腾，蒸笼摞得高。
  → 逼出动作：一路每笼都冒热气，宝宝的馋被反复勾起，每走一步就被勾一下（欲望层叠，天然适合贯穿物蒸笼）。
- 特征：游客在体验区可以亲手包芋饺、制米浆、锤肉馅。
  → 逼出动作：任务前先被拉去学艺，锤肉馅太用力、包芋饺包不拢（"他做的东西能不能吃"的小考验）。
- 特征：村里有千年古樟树、廊桥、清泉，游客游廊桥、看樟树、酌清泉。
  → 逼出动作：在古樟下集合出发，过木廊桥时蒸笼在桥上晃。
  来源：https://zhuanti.mct.gov.cn/xcss2024_xcyfw/fujian/detail/7474.html （已打开，文旅部官网）

## 5. 宁化石壁客家祖地（祭祖圣地，庄重）
- 特征：进景区先过"客家祖地"牌楼，走一条500多米的"客家之路"，经寻根路、溯源桥到公祠。
  → 逼出动作：一路是有仪式感的长路，端着东西也不敢嬉闹、脚步放轻（庄重本身就是动作约束）。
- 特征：正殿玉屏堂里供奉着160多个姓氏的始祖神位，可同时供数百人祭祖。
  → 逼出动作：进堂必须轻、慢、恭敬；宝宝想笑想吃，被同伴一把捂住嘴（笑点只在"忍住"）。
- 特征：景区有擂茶馆，可喝客家酒酿、擂茶；祭祖大典有金铳、仪仗、乐舞。
  → 逼出动作：擂茶要来回捣（手活）；金铳/乐舞突然响起时宝宝被吓一跳；热情地被人端茶。
  来源：https://m.baike.com/wiki/%E5%AE%A2%E5%AE%B6%E7%A5%96%E5%9C%B0/1152401 （已打开）
  风险提示：与红军街同类，本站不安排"搞破坏/误会"型笑点，只拍"被庄重气氛收服"。

## 6. 尤溪南溪书院（朱熹出生地，安静向学）
- 特征：文公祠前有一片方形小水塘"半亩方塘"，波光粼粼，"源头活水"出处。
  → 逼出动作：临水石板路，倒影在水里，东西怕掉下去（水的视觉预兆，且塘是方的，呼应"平"）。
- 特征：书院旁有两株古樟"沈郎樟"，枝干参天，相传为朱熹幼时所植。
  → 逼出动作：大树下是读书处，宝宝小声学规矩、肚子叫被"嘘"（在安静地方憋动静）。
- 特征：书院区有韦斋祠、毓秀亭和高14米的朱熹塑像，开蒙讲堂做孩童教学。
  → 逼出动作：在塑像/学堂前正襟危坐，蒸笼只能藏在身后（不该带吃的进书院）。
  来源：http://culture.people.com.cn/n1/2020/0130/c1013-31564754.html （已打开，人民日报）
